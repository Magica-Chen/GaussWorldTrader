01   Set up the workspace

TERMINAL / PYTHON 3.12+
git clone https://github.com/Magica-Chen/GaussWorldTrader.git
cd GaussWorldTrader
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env

Edit your local .env for connected features. Run the session service on Linux, macOS, or WSL.

RUN FROM THE REPOSITORY ROOT
python -m streamlit run examples/dashboard_preview.py
